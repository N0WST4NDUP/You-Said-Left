# You Said Left

한 명은 운전하고, 한 명은 지도를 읽으며 목적지까지 도착하는 2인 협동 운전 게임.

마인크래프트의 지형 생성 기법을 참고한 랜덤 지형에 GTA 산안드레스처럼 주행할 수 있는 도로망을 만드는 것이 목표다. 지상도로·경사·터널·교량·고가도로를 같은 청사진으로 3D 도시와 지도에 표현한다. 현재 구현은 기본 지형·높이·공통 수면까지이며, 입체 도로망은 아직 구현하지 않았다.
